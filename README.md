# 汉服租赁管理系统

## 项目简介
基于 Vue3 + Element Plus + SpringBoot + MyBatis-Plus 的汉服租赁平台

## 技术栈
- **前端**: Vue3 + Element Plus + Vite + Pinia + Vue Router
- **后端**: SpringBoot + MyBatis-Plus + MySQL + JWT
- **数据库**: MySQL 8.0

## 项目结构
```
├── vue/                    # 前端项目
├── hangfuzhulingxit/       # 后端项目
└── docs/                   # 文档
```

## 功能模块
1. 角色权限与用户中心
2. 系统配置与公告
3. 汉服商品管理
4. 租赁交易模块
5. 库房作业与物流
6. 归还验收与售后
7. 信用与财务管理
8. 统计驾驶舱
